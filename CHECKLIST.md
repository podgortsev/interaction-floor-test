# Release bar

The eight lines a tool has to pass before it is published. Checked 2026-11-10,
Python 3.11.9 on Windows, from a clean clone of this repository. A line is
ticked only with the evidence beside it.

| | line | evidence |
|---|---|---|
| [x] | 1. Installs and runs from a clean clone, with one command written in the README | `python floor_test.py examples/clean.csv`, standard library only, nothing to install |
| [x] | 2. The README opens with the problem in two sentences, then the command, then the output of that command, copied from a real run | the output block is `examples/clean.expected.txt`, written by the tool; test section 11 fails if the tool's output ever differs from that file |
| [x] | 3. One worked example a stranger can run in under a minute | both examples run in under one second |
| [x] | 4. Tests pass, and they test the logic, not that the file imports | 63 checks pass: known-answer verdicts, false-alarm rates over 150 and 30 seeds, the two-test rule, strata, direction labels, refused inputs, the examples |
| [x] | 5. Fails loudly on bad input rather than returning a plausible number | exit 1 with the line number for a missing column, unknown kind, duplicated item, empty, non-numeric, NaN or infinite cell, no rows, no floor pair; tested in section 4 |
| [x] | 6. Does nothing over the network unless that is the point of the tool, and says so if it does | no network code; the README says so |
| [x] | 7. No dependency that costs money, and no API key required to try it | imports: csv, json, math, random, sys |
| [x] | 8. The claim in the README is exactly what the tool does, with no "coming soon" | every verdict, exit code and refusal in the README has a test; the Paper 3 claims restate the instrument table in the paper's README |

## Rules

- Not a CRM, marketing, revenue or integration deliverable: a measurement check
  for bias audits.
- Nothing negative about any company, product, project or person. Example data
  is synthetic, generated by `make_examples.py` from a fixed seed.
- Free and local: no service, no GPU, no key.
- Research claims stay inside what the paper shows: the "Where it comes from"
  section restates the instrument table in Paper 3's README and nothing beyond
  it.
- English in every file. No em-dashes.

## Publication

Passing the bar is not itself the decision to publish. That is made per tool,
separately, after the bar.
